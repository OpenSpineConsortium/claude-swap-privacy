# Claude Swap Cloud: privacy policy and support

This repository holds the privacy policy of the Chrome extension "Claude
Swap Cloud" (`PRIVACY.md`, the same text the extension's package carries;
the extension was named "cswap project import" until 2026-10-07) and takes
questions about it through its issues. The extension and the `cswap`
command line it works with (the `claude-swap-cloud` package) are developed
in a private repository; the package on the Chrome Web Store is the
extension's own code, minified as the store allows and nothing more, with
no build step in the repository.

Claude Swap Cloud is not an Anthropic product. "Claude" and "claude.ai" are
Anthropic's marks, used here only to say which site the extension works with.
