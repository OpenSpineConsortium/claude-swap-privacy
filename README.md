# cswap project import: privacy policy and support

This repository holds the privacy policy of the Chrome extension "cswap
project import" (`PRIVACY.md`, the same text the extension's package
carries) and takes questions about it through its issues. The extension
and the `cswap` command line it works with are developed in a private
repository; the package on the Chrome Web Store is the extension's full
source, plain files with no build step.

cswap is not an Anthropic product. "Claude" and "claude.ai" are Anthropic's
marks, used here only to say which site the extension works with.
