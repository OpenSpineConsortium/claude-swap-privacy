# Claude Swap Cloud: privacy policy and support

This repository holds the privacy policy of the Chrome extension "Claude
Swap Cloud" (`PRIVACY.md`, the same text the extension's package carries;
the extension was named "cswap project import" until 2026-10-07) and takes
questions about it through its issues. The extension and the `cswap`
command line it works with (the `claude-swap-cloud` package) are developed
in a private repository and installed from PyPI; the package on the
Chrome Web Store holds all of the extension's code, the import and export
scripts it runs included, minified as the store allows and nothing more,
with no build step in the repository.

The extension's use of the information it receives complies with the
Chrome Web Store User Data Policy, including its Limited Use requirements;
`PRIVACY.md` says what it handles and where it goes.

Claude Swap Cloud is an independent tool, not an Anthropic product, and is
not made, endorsed or sponsored by Anthropic. "Claude" and "claude.ai" are
Anthropic's marks, used here only to say which site the extension works with.
